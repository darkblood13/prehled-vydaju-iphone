# Přehled výdajů pro iPhone

Bezplatná webová aplikace pro evidenci výdajů. Otevři v Safari a přes Sdílet → Přidat na plochu vytvoř ikonu.

Tento repozitář obsahuje pouze sestavenou webovou verzi. Osobní výdaje a screenshoty se sem neukládají; po přihlášení se synchronizují přes soukromý prostor aplikace na vlastním Google Drivu. [Jak aplikace zachází s daty](privacy.html).
